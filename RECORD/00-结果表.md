# 实验一 结果表

本表为实验的核心产出，数据须与 `predictions.jsonl` 中的逐条记录一致。每行填写后注明运行标识，便于回溯到 `RECORD/01-实验配置.md`。

## 一 主结果表

训练与评测完成后填写。

| 方法 | GSM8K Accuracy | ARC-Challenge Accuracy | 运行标识 |
| --- | --- | --- | --- |
| Base Model | 0.6020 | 0.5205 | R2-13 与 R2-14 |
| Full SFT | 0.5125 | 0.5444 | R2-13 与 R2-14 |
| LoRA | 0.4435 | 0.5734 | R2-15 |
| P-Tuning v2 | 0.3829 | 0.4991 | R2-15 |
| 自研方法 |  |  |  |

Base Model 一行取同一机型上的重评读数，即 R2-13 的 GSM8K 794/1319 与 R2-14 的 ARC 610/1172，使基线与三种方法处于同一硬件与同一精度。R1-1 在 V100 上的读数为 GSM8K 0.6035 与 ARC 0.5205，两个 GSM8K 读数相差 2 条样本，低于一个标准误，故替换不改变任何结论，原读数保留作硬件间的一致性核对。ARC 列的四种方法读数由本机按 v3 抽取规则离线重算，生成侧未重跑，原先判对的样本无一条改动，理由见 `RECORD/01-实验配置.md` 第五节。v2 严格口径下的 ARC 读数为 0.5205、0.5290、0.4642 与 0.3805，列为稳健性对照，不入主表。

## 二 评测元信息

同一次评测的全部方法须共用以下配置。

| 项目 | 取值 |
| --- | --- |
| GSM8K 测试样本数 | 1319 |
| ARC-Challenge 测试样本数 | 1172 |
| ARC 选项个数分布 | 4 选项 1165 题，3 选项 4 题，5 选项 3 题 |
| ARC 随机猜测期望准确率 | 0.2502 |
| GSM8K 二项分布标准误参考 | 约 1.38 个百分点，p 取 0.5 |
| ARC 二项分布标准误参考 | 约 1.27 个百分点，取随机猜测水平 |
| 评测日期 | 2026-10-17，Base Model 另有 2026-10-13 的 R1-1 一次 |
| 答案抽取规则版本 | v3。R1-1 任务内所装为 v1，P2.6 各段所装为 v2，全部读数经本机离线按 v3 重算，理由见 `RECORD/01-实验配置.md` 第五节 |
| ARC 抽取失败率，v3 | 0、0.0768、0.0333、0.0904，依次为 M0 至 M3 |
| ARC 抽取失败率，v2 | 0、0.0973、0.2381、0.2952，依次为 M0 至 M3，保留为稳健性对照 |
| ARC 截断率 | 0.0009、0.4514、0.2696、0.0034，依次为 M0 至 M3，不随抽取规则改动 |
| 解码配置 | 贪心，`do_sample` 为 False，生成上限两数据集均取 512 |
| enable_thinking | False |

两个标准误用于判断方法间差异是否超出抽样误差。GSM8K 上 1.38 个百分点对应约正负 2.7 个百分点的百分之九十五置信区间，ARC 上 1.27 个百分点对应约正负 2.5 个百分点。小于该幅度的差异不构成证据。

## 五 现象记录

记录与预期不符的观察。抽取失败样例、输出格式异常、训练损失不收敛等现象均记于此，供结果分析引用。

| 现象 | 涉及方法 | 出现规模 | 初步判断 |
| --- | --- | --- | --- |
| ARC 抽取规则 v1 在末位级误取正文末字母 | Base Model | 降级 39 条与失败 45 条 | 模型多以标签点号接选项正文作答，短输出的末位是正文末字母如 F 与 s，既不在本题标签集合内又中止了级联。v2 改为只认本题标签并下沉，84 条中 83 条接住，余 1 条是截断的长解释文本，仍在降级样本中 |
| GSM8K 训练目标格式未迁移 | Base Model | 828 条含盒式值，491 条使用 `####` 标记 | 基座未经指令微调，标记命中率 0.3722，主要抽取量落在引导语级 820 条。末值兜底 8 条全部判错，与截断及跑偏样本重合 |
