# 三种微调方法

本篇说明监督微调在优化什么，参数高效适配为什么能成立，以及 LoRA 与 P-Tuning v2 的具体做法。相关代码为 `exp1/src/methods/` 下的三个模块，超参取值见 `RECORD/01-实验配置.md`。

## 一 监督微调在优化什么

监督微调把一条样本拆成输入与目标两段，让模型在给定输入时逐字预测目标，损失是每个目标 token 上的交叉熵之和。输入那一段的损失被掩掉，不计入梯度，因为要学的是如何作答而不是如何复述题目。

本实验的目标文本取 GSM8K 的解题过程，并剥离其中的 `<<计算式=结果>>` 标注。剥离的理由是这类标注是数据集的书写约定而非自然语言，模型学到它会耗费容量去记一种格式，而该格式在评测时并不出现。

全参微调更新全部 596,049,920 个参数。它的记忆能力最强，代价是显存与存储都按全量参数计，且参数在整个空间里移动，原有能力最容易受影响。

## 二 参数高效适配为什么能成立

神经网络的参数远多于拟合当前任务所需，解空间里存在大量效果相近的点。已有观察表明，把参数更新限制在一个低维子空间里，效果可以接近全参微调。这一观察是参数高效适配的前提。

各类方法的共同做法是冻结基座的全部参数，另插入一小批可训练量，只更新这一批。可训练量占全模型的比例因此成为方法的固有属性，也是横向比较时须一并报告的项，本实验的取值为 LoRA 的 2,293,760 即 0.003834 与 P-Tuning v2 的 1,146,880 即 0.001920。

冻结基座只限制了参数可移动的范围，并不保证新参数落在与原能力相容的方向上。遗忘是否随可训练量按比例缩小，是一个须由实验回答的问题，不可先验假定。

## 三 LoRA

LoRA 不改动原权重，而在其旁挂一对低秩矩阵。对某个权重矩阵 W，前向变为 W 加 BA 乘缩放系数，其中 B 为输出维度乘秩、A 为秩乘输入维度，秩远小于两者。缩放系数取 alpha 除以秩，本实验的秩为 8、alpha 为 16，故系数为 2。

初始化的安排有讲究。A 取随机而 B 取零，故训练开始时 BA 恰为零矩阵，模型输出与基座完全一致，训练从基座这一点出发而不是从扰动过的点出发。

LoRA 只挂在注意力投影上，按后缀匹配 q_proj、k_proj、v_proj 与 o_proj，共 112 处。挂载位置越多，可训练量越大，能改变的行为也越多。

推理时可以把 BA 加回原权重，得到一个与原模型同构的权重矩阵，不增加前向开销。这是 LoRA 相对其他适配方法的一项工程优势，本实验的检查点仍以适配器形式保存，加载时再由 peft 合并。

可训练量小意味着每一步的有效更新幅度受限，故 LoRA 的学习率通常高于全参微调，本实验取 1.0e-4 对 2.5e-5。

## 四 P-Tuning v2

P-Tuning v2 不碰权重，而在每一层的注意力里插入一组可训练的键值对，称为前缀。模型前向时把前缀接在真实序列之前参与注意力计算，其作用相当于给每一层提供一段可调的上下文。

本实验的前缀长度为 20，插入全部 28 层，故可训练量为 20 乘 2 乘 1024 乘 28，恰为 1,146,880，其中 2 指键与值各一份，1024 为隐藏维度。

早期做法只在输入层拼一段可训练向量，层数一深效果就明显衰减。逐层插入是 v2 的核心改动，它使每一层都能直接调整，而不必靠传播。

前缀不经过重参数化网络，各层的向量直接作为可训练表优化。前缀的初始化可取置零或随机，本实验取随机，理由是同等学习率与轮数下随机一侧的开发集读数显著更高，见 `RECORD/01-实验配置.md` 第三节。

置零并不等于不作用。前缀即使初值为零，仍以零得分参与注意力的归一化，从而改变真实位置的权重分配，故置零起点与基座不等价。这也是该方法需要较大学习率的原因，本实验取 1.2e-2，比全参微调高三个量级。

## 五 三者的取舍

可训练量与效果不呈单调关系。本实验的最终配置在开发集上的读数为全参微调 221 条、LoRA 194 条与 P-Tuning v2 174 条，同一配置在测试集上均低于未训练基线。可训练量最小的 P-Tuning v2 并未因参数少而占优，其原因至少包括优化难度更高与适配位置不同两层，须结合损失曲线解读，不能归结为参数多少一项。

## 六 可以自己想的两个问题

LoRA 的 B 若也取随机而非零，训练起点会偏离基座，这种偏离在短轮数训练下是利是弊。

P-Tuning v2 只增加前缀而不改动任何权重，它是否应当比 LoRA 遗忘更少。若实测相反，可能的解释有哪些。
