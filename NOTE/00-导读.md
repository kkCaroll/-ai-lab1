# 实验一 学习笔记 导读

本目录记录实验过程中新学到的概念，按主题分篇。各篇不重复实验操作步骤，只写理解性的知识，供撰写报告与现场问答时取用。

## 一 笔记清单

| 文件 | 主题 | 主要对应阶段 |
| --- | --- | --- |
| `01-从文本到模型输入.md` | 分词、特殊标记、对话模板、思考模式开关 | P1.1 |
| `02-prompt的形态.md` | 零样本、少样本、指令的两种功能 | P1.1 |
| `03-批量推理.md` | 自回归、填充方向、注意力掩码、位置编码、KV 缓存 | P1.4 |
| `04-解码策略.md` | 贪心、采样、束搜索及其取舍 | P1.4 |
| `05-如何量一个模型.md` | 答案抽取、精确匹配、二项标准误、配对检验 | P1.2 与 P1.6 |
| `06-为什么要留一块数据.md` | 开发集、数据泄漏 | P1.5 |
| `07-本实验要回答什么.md` | 灾难性遗忘、参数高效适配、缓解思路 | P1.6 与 P3 |

## 二 阅读顺序

`01` 与 `03` 是地基，讲清楚模型这一侧在做什么。`02` 与 `04` 讲输入的构造与输出的选择，是两组可以独立调整、但一旦固定就不得在方法间变动的量。`05` 与 `06` 讲测量的原理，是读懂结果表的前提。`07` 回到实验本身要回答的问题，可在读过 `05` 之后再看。

## 三 记录约定

现象与结论分开记。凡本机或容器内实测得到的数字，注明来源文件与日期。凡引自资料的说法，注明出处。尚未验证的推断明确标出，不写成结论。这与 `LOG/02-问题与解决.md` 的「根本原因栏在查清之前留空」是同一套约定。
