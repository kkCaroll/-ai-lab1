# 本实验要回答什么

本篇回到实验本身，说明问题的设定、五种方法的定位、灾难性遗忘的机制直觉，以及结果应当怎么读。相关内容对应 `PLAN/01-任务分解.md` 的阶段划分与 `RECORD/00-结果表.md`。

## 一 问题设定

用 GSM8K 这个小学数学应用题数据集去微调 Qwen3-0.6B，同时在 ARC-Challenge 这个科学常识选择题数据集上观察模型的原有能力是否下降。前者衡量领域适配的效果，后者衡量代价。实验要回答的是不同适配方法在「变强多少」与「退步多少」之间的取舍有何差异。

ARC-Challenge 只用于评测，不参与训练。它不是本实验的目标领域，而是用来观测遗忘的探针。若把它也用于训练，探针就被污染了，因为它测的将是模型在新领域上的学习能力而非原有能力的保持情况。

## 二 五种方法的定位

M0 是不做任何训练的原版模型。它提供坐标系的原点，后续每一个读数都要减去它才有意义。

M1 全参数监督微调更新模型的全部权重。它是效果的上界参照，通常提升最大，同时遗忘也最严重，因为它允许参数在整个空间里移动。

M2 与 M3 属于参数高效适配。LoRA 在原有权重旁挂低秩矩阵，训练时只更新这批小矩阵，参与训练的参数占比通常不到百分之一。P-Tuning v2 则在输入序列前拼接一组可学习的前缀向量，冻结基座全部参数，只训练前缀。两者的共同思路是限制参数的移动范围，从而在适应新领域时少碰承载通用能力的那部分参数。

M4 是自研方法，需要在 P2 的结果上确定具体方案，限定条件见下节。

## 三 灾难性遗忘的机制直觉

一个够用的直觉如下。梯度下降把参数推向使当前批数据损失下降的方向，而这个方向由当前数据的分布决定。GSM8K 的七千条样本分布很窄，全是同一类小学数学题，措辞与推理形式高度同质。模型在这批数据上反复下降，会向这个窄分布过拟合，而它原本承载通用知识的参数区域在这个过程中被覆盖掉了一部分。

这个过程本身并不神秘，它只是普通优化在分布偏移下的自然结果。神经网络把知识分散储存在大量参数上，新任务的最优解与旧任务的最优解通常不同，而优化过程只关心新任务的损失。遗忘是优化目标与旧能力之间没有约束连接的必然后果。

一个值得注意的对照是，M2 与 M3 只更新极少参数，遗忘却未必按参数比例缩小。可训练参数少只限制了参数空间的可达范围，并不直接保证新参数落在与原能力相容的子空间里。这正是 M4 要处理的问题。

## 四 M4 的候选手段

计划中对 M4 限定了四类思路，见 `PLAN/02-风险与验证清单.md` 中 R6 的应对栏。

第一类是进一步压低可训练参数占比，例如降低 LoRA 的秩。参数越少，能承载的新知识越少，提升也随之受限，存在一个需要实验确定的平衡点。

第二类是在训练目标中加入相对基座输出的约束。做法是把基座模型当作锚，训练时同时计算基座在当前输入上的输出分布，并在损失中加入一项惩罚，使新模型的输出分布不要偏离它太远。这个惩罚项的作用类似正则，用来把参数拴在原能力附近。它需要额外一次前向，训练开销约增加一半。

第三类是参数空间约束，例如只更新与特定功能相关的模块，或对新参数施加显式的范数限制。

第四类是早停，即在新领域损失下降趋于平缓但遗忘尚未加剧时就停止训练。实现最简单，效果依赖于对遗忘的监控手段，可能需要一轮中间评测。

## 五 结果应当怎么读

判读的基本形式是把两个数据集上的读数与 M0 相减，得到一组增益与一组损失。

若 GSM8K 上升而 ARC 同步下降，是典型的灾难性遗忘，下降幅度即代价。若 GSM8K 上升而 ARC 基本持平，说明该方法在提升领域能力的同时较好地保住了原有能力。若 GSM8K 上升而 ARC 也上升，需要谨慎对待，先排查是否存在测量问题，例如新的输出格式恰好更契合 ARC 的抽取规则。

判读时还有两个陷阱。其一是差异小于抽样误差。GSM8K 与 ARC 的标准误分别约 1.38 与 1.27 个百分点，两个方法之间小于三个点的差异不宜作为证据，须以 P4 的配对检验为准。其二是 ARC 上的信号可能本就很弱。若 M0 在 ARC 上的读数已接近随机猜测期望 0.2502，那么任何方法在该数据集上的变化都容易淹没在噪声里，此时应以通用文本的困惑度作为辅助指标，对应风险 R11。

## 六 可以自己想的三个问题

GSM8K 的基线若显著高于同类模型，应当如何解释，又该如何在报告中处理。

P-Tuning v2 只增加前缀向量而不改动任何原有参数，它是否应当表现出比 LoRA 更小的遗忘。如果实测结果相反，可能的解释有哪些。

M4 若采用以基座输出做约束的思路，这个约束在训练时应当施加在哪些输入上。用 GSM8K 的训练样本最方便，但这些样本恰好也是模型即将过拟合的那批数据，约束在这批数据上被满足是否等于原能力被保住。
