尺子由三段构成且每段可单独验证。输入侧模板单源，训练与评测渲染到 assistant 起始位置逐字节相同，提示校验和经独立复算与运行内所记一致。输出侧抽取规则独立成模块并带版本号，数值侧三级级联与标签侧四级级联各记命中计数，二十八条真实输出冻结为回归用例，任一条取值偏离即报错。评测侧自行实现批量生成，左填充配显式注意力掩码与位置编号，批量与单条生成逐字符一致已由两次自检确认。

M0 的读数为 GSM8K 0.6035 与 ARC-Challenge 0.5205，运行标识 R1-1。ARC 的百分之九十五置信区间下限为 0.4919，远离 0.2502 的随机猜测期望，故该侧读数不由猜测噪声主导，方法间差异是否显著仍以约 2.9 个百分点的区间半宽为准。GSM8K 上基座未经指令微调，`####` 标记命中率仅 0.3722，主要抽取量落在引导语级，该值已单列记录，训练后应显著上升。

### 已定决策

以下五项于 2026-10-12 确定。实施中如需变更，须同时更新 `RECORD/01-实验配置.md` 并说明理由，不得只改代码。

| 项目 | 取值 | 依据 |
| --- | --- | --- |
| GSM8K 抽取口径 | 宽松为主，先取 `####` 标记，无标记时依次回退至引导语后的数值与全文末值，另记格式命中率 | 基座模型不使用 `####`，严格口径会把基线压至近零，见 `LOG/02-问题与解决.md` Q2 |
| ARC 抽取口径 | 四级级联，依次为引导语、末位、正文比对、前置标签，前两级只认本题标签集合内的字符，取到集合外者记下备作降级并下沉 | 末位级原取任意孤立字符，在标签接正文的作答形态上误取正文末字母并中止级联，见 `LOG/02-问题与解决.md` Q9 与 `RECORD/01-实验配置.md` 第五节 |
| prompt 模板 | 零样本指令式，单轮 user 消息，含显式输出格式约束 | 训练序列短，且训练与评测模板可完全一致，见 R8 |
| 开发集规模 | 400 条，固定种子，五种方法共用同一划分 | 标准误约 2.5 个百分点，足以区分学习率量级差异，见 R7 |
| 训练目标文本 | 剥离 `<<...>>` 计算标注 | 使训练目标与评测期望的输出形态一致 |
| 解码配置 | 贪心，`do_sample=False`，生成上限 GSM8K 取 512、ARC 取 128 | 采样会引入与方法无关的噪声，见 R13 |

### 数据集事实

ARC-Challenge 测试集 1172 题中有 22 题的选项标签为数字 1 至 4，其余为字母。抽取规则不得硬编码字母表，须由题目自带的标签集合驱动。选项个数分布为 4 选项 1165 题、3 选项 4 题、5 选项 3 题。

GSM8K 训练集 7473 条答案的末尾取值全为整数，其中 79 条含千分位逗号，无分数、无小数、无缺 `####` 标记的样本。

### 验收条件

P1.0 以导入成功并可打印一次三态报告为准。P1.1 要求打印同一条样本的训练输入与评测输入并逐字符比对，两者只应在 assistant 一轮上分岔。P1.2 与 P1.3 要求单元测试全绿，且回退规则以 Q2 记录的真实输出为用例。P1.4 要求先在本机以处理器运行小样本端到端，并满足同一条样本单条生成与批量生成结果一致这一不变量，再上 DLC 跑全量。P1.6 要求任务退出码为零且报告无失败项，取回的两个明细文件条数为 1319 与 1172，抽取失败率为零或极低。

### 对 P2 的约束

训练入口须复用 `src/data.py` 的模板函数，不得另写一份。评测入口的批量生成实现须可被训练过程中的中间评测复用。开发集索引文件须在训练时被剔除，正式训练集为 7073 条。
